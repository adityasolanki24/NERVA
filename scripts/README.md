# Scripts

Small tools around the Open Duck baseline.

| Script | Purpose |
|---|---|
| `check_open_duck_baseline.py` | Headless check of the pretrained walking policy (stability, velocity tracking) |
| `render_policy.py` | Render a policy rollout to video |
| `compare_reference_pickles.py` | Compare two reference-motion files (e.g. regenerated vs shipped) |
